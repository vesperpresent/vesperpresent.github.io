# Vespa

Free church presentation software. Live at https://vesperpresent.github.io/

- `index.html` landing page
- `admin.html` admin page (songs, sermons, scripture, photos, videos, services)
- `projector.html` projector page (front and back screens)
- `output.html` front screen window (`?view=stage` for the back screen)
- `remote.html` phone remote

To change the logo, replace `assets/img/logo.svg`.
